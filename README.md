Riddarna af Bardhe ⚔️

This project is a custom-built website for Riddarna af Bardhe, a knight association.
The site is being developed entirely from scratch — from design and structure to functionality — and is built solo as a real-world, long-term project.

The goal is to create a clear, engaging, and maintainable web presence for the association, covering information, events, and recruitment.

--- 🚧 Work in Progress
This project is actively under development and will continue to evolve as new features and content are added. ---

🎯 Project Goals
- Design and develop a complete website from the ground up
- Create a clear information hub for the association
- Make it easy for visitors to learn about:
    - The association
    - The knights
    - The horses
    - Events and activities
- Encourage engagement and new member sign-ups

✨ Planned Features
- Informational pages about the association and its history
- Dedicated sections for:
    - Knights
    - Members
    - Events
- Event calendar for upcoming activities
- Contact information and inquiry forms
- Clear call-to-action to join the association
- Responsive design for desktop and mobile
- Ongoing improvements to UI, accessibility, and performance

🧠 Scope & Responsibility
Design: UX/UI, layout, visual identity
Development: Frontend architecture and logic
Content structure: Information hierarchy and navigation
Maintenance: Continuous updates and improvements

This project is developed independently, from initial concept to final implementation.
